    3. Б.3 - Подписывание данных: ссылка-ваучер брони
        3.1 Добавлены файлы bookings/voucher.py, шаблон bookings/voucher.html, в файл bookings/view.py добавлена функция booking_voucher(), в маршрутах bookings/urls/py добавлен новый маршрут на страницу ваучера.

            4) Показ ваучера, если ссылка действительна и бронь подтверждена.
            5) Возвращается HTTP 404, если токен подделан, просрочен, некорректен либо относится к бронированию, которое не должно выдавать ваучер.
        3.2 В файл bookings/tests.py добавлен класс BookingVoucherTests. Условия тестов для Б.3:

            3) Просроченный токен возвращает HTTP 404.
            4) Для бронирования со статусом pending ваучер недоступен — HTTP 404.
            5) Для подтверждённого бронирования ссылка действительно содержит подписанный токен.
